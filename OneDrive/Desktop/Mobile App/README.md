# 🎓 PrepMaster

PrepMaster is a modern, lightweight, and interactive mobile revision application designed to help students study, revise, and organize their learning materials. 

This project is **purely vibe coded** (developed entirely using AI pair-programming and agentic assistant workflows), and packaged for mobile devices via **Capacitor** for a fluid, native app-like experience with premium aesthetics.

---

## 🌟 Key Features

- **Interactive Subjects Dashboard**: Browse core subjects (Mathematics, Physics, Chemistry, Biology) complete with custom subject-specific icons and topic counts.
- **Topic Explorer**: Drill down into specific subjects to view their full list of topics.
- **Rich Study Materials**: Detailed view cards for each topic featuring:
  - Formatted text and explanations.
  - Code/preformatted code blocks (`<pre><code>`).
  - Styled equations, definitions, and unordered/ordered lists.
- **Quick Revision (Favorites)**: Star key topics to pin them directly to the **Quick Revision** section on your home dashboard for instant access.
- **Instant Search**: Search through all subjects and topics in real-time with responsive, on-the-fly filtering.
- **JSON Data Manager**: Fully customize the app's curriculum! Import (upload), export (download), or reset the entire subjects and topics database directly inside the app.
- **Local Persistence**: User settings, starred topics, and custom course content are automatically persisted using browser `localStorage`.
- **Native Android Integration**: Powered by Capacitor to enable native runtime execution and packaging on Android devices.

---

## 🛠️ Technology Stack

- **Development Paradigm**: Purely Vibe Coded (AI Assisted development)
- **Frontend Core**: HTML5, CSS3 (featuring custom CSS variables, glassmorphism, responsive safety zones for notch displays, and page transitions), Vanilla ES6 JavaScript.

- **Native Bridge**: [Capacitor](https://capacitorjs.com/) (`@capacitor/core`, `@capacitor/cli`, `@capacitor/android`).

## ⚙️ Getting Started

### Prerequisites

To run this project, make sure you have the following installed:
- [Node.js](https://nodejs.org/) (LTS recommended)
- [Android Studio](https://developer.android.com/studio) (for running/building on Android)
- Android SDK and platform tools

### Installation

1. **Clone the Repository**
   ```bash
   git clone https://github.com/vrushank-srikar/Prep-Master.git
   cd Prep-Master
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Sync Capacitor**
   Sync your web assets with the native Android project:
   ```bash
   npx cap sync
   ```

### Running the App

#### A. In the Browser (Development)
You can run the web portion directly. Open `www/index.html` in any web browser, or use a local dev server (like Live Server in VS Code).

#### B. On Android (Emulator or Device)
1. Open the project in Android Studio:
   ```bash
   npx cap open android
   ```
2. Build and run the app directly from Android Studio onto your connected device or an emulator.

## 📋 Customizing Curriculum (JSON Schema)

PrepMaster allows you to load custom course materials using the built-in **Data JSON Manager**. You can upload a JSON file conforming to the following structure:

```json
[
  {
    "id": "sub_math",
    "title": "Mathematics",
    "icon": "📐",
    "topics": [
      {
        "id": "top_math_calculus",
        "title": "Calculus & Limits",
        "description": "<p><strong>Calculus</strong> is the study of continuous change...</p>"
      }
    ]
  }
]
```

### JSON Fields Breakdown:
- **`id`**: Unique identifier for the subject (e.g. `sub_physics`).
- **`title`**: Name of the subject displayed in cards.
- **`icon`**: An emoji or symbol representing the subject.
- **`topics`**: An array of topic objects.
  - **`id`**: Unique identifier for the topic (e.g. `top_phys_mechanics`).
  - **`title`**: Topic header.
  - **`description`**: Topic body content (accepts HTML tags like `<strong>`, `<pre><code>`, `<ul><li>` for rich formatting).
